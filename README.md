## Customization

### Colors

Edit the CSS custom properties in `style.css`:

```css
:root {
  --lime: #65A30D;
  --lime-light: #84CC16;
  --lime-dark: #4D7C0F;
  --dark: #1A1A2E;
  --dark-light: #16213E;
}
```

### Fonts

Change the font imports in HTML files:

```html
<link href="https://fonts.googleapis.com/css2?family=Your+Font:wght@400;500;600;700&display=swap" rel="stylesheet">
```
